# Комментарий (comment)

**Комментарий** — бағдарламаның ішінде программистке түсініктеме беру үшін жазылатын мәтін. Комментарийді компьютер орындамайды, яғни ол бағдарлама жұмысына әсер етпейді.

C++ тілінде комментарийдің 2 түрі бар:

### 1. Бір жолдық комментарий — `//`

`//` таңбасынан кейін жазылған мәтін сол жолдың соңына дейін комментарий болып саналады.

```cpp
// Бұл бір жолдық комментарий
```

### 2. Көп жолдық комментарий — `/* ... */`

Егер комментарий бірнеше жолдан тұрса, `/*` және `*/` қолданылады.

- `/*` — комментарийдің басталуы
- `*/` — комментарийдің аяқталуы

```cpp
/*
Бұл көп жолдық
комментарий
*/
```

### Комментарийлер бірнеше мақсатта қолданылады:

1. Кодты түсіндіру үшін
2. Күрделі формуланың мағынасын көрсету үшін
3. Кодтың белгілі бір бөлігінің қызметін жазу үшін
4. Басқа программист кодты оңай түсінуі үшін
5. Өзіміз жазған кодты кейін қайта қарағанда түсіну үшін

# Арифметикалық операторлар

| Оператор | Мағынасы | Мысал | Нәтиже |
|---|---|---|---|
| `+` | қосу | `10 + 5` | `15` |
| `-` | азайту | `10 - 5` | `5` |
| `*` | көбейту | `10 * 5` | `50` |
| `/` | бөлу | `10 / 5` | `2` |
| `%` | қалдық | `10 % 3` | `1` |

Берілген мысал:

```cpp
int a = 10;
int b = 3;

cout << a + b << endl;
cout << a - b << endl;
cout << a * b << endl;
cout << a / b << endl;
cout << a % b << endl;
```

# Салыстыру операторлары

Салыстыру операторлары екі мәнді салыстырады.

Нәтижесінде `true` немесе `false` мәні алынады.

| Оператор | Мағынасы |
|---|---|
| `==` | тең |
| `!=` | тең емес |
| `>` | үлкен |
| `<` | кіші |
| `>=` | үлкен немесе тең |
| `<=` | кіші немесе тең |

```text
true = 1
false = 0
```

Мысалдар:

```cpp
cout << (10 > 5);      // true
cout << (10 < 5);      // false
cout << (10 == 10);    // true
cout << (10 != 10);    // false
cout << (10 >= 10);    // true
cout << (5 <= 10);     // true
```
